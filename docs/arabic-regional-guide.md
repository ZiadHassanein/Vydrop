# Understanding Arabic video-download requests

Vydrop is a free, MIT-licensed Windows video and audio downloader by Ziad Hassanein. Its interface supports English and Arabic. This guide explains how illustrative Arabic requests map to the same app controls, for readers across the 22 Arab countries and people helping them use the app.

## One task, several ways to ask

Arabic speakers may use words corresponding to download, save or bring down a video. Names for a computer also vary: a desktop, laptop, PC or «حاسبة» can all mean the Windows computer where the file will be stored. A request for the video's sound means **Audio**, while a request for picture and sound means **Video**.

The examples below are explanatory wording, not keyword-volume research or a claim that one phrase represents every speaker in a country. Plain Arabic is used for some multilingual communities. The country list follows the [UN's 22-country Arab-region grouping](https://www.un.org/en/chronicle/article/mdgs-western-asian-region-regional-cooperation-and-policies-needed-promote-development).

## Map the request to the actual controls

- **Keep picture and sound:** choose Video and an inspected compatible MP4, MKV or WebM output.
- **Keep only the sound:** choose Audio and MP3, M4A, Opus, WAV or FLAC. Output quality remains limited by the original source.
- **Save subtitles:** use Subtitles and an available SRT or VTT track. This saves an exposed caption file; it does not create a new translation.
- **Save several videos:** use Queue for separate links or choose entries from a playlist. Arabic and borrowed forms of “playlist” describe the same feature.

## Start with a precise public video link

Download the [official Windows package](https://github.com/ZiadHassanein/Vydrop/releases/download/v4.4.4/Vydrop-v4.4.4-win-x64.zip), extract the ZIP and open Vydrop.exe. Paste the video's own link, wait for checking inside the Download button, then choose output, quality and destination. A Facebook or TikTok homepage does not identify a specific video.

The optional [Chrome, Edge and Firefox companion](browser-extension-setup.md) can resolve a detected playing video and send its link to the app. It does not import browser accounts or cookies. You review the result and start the download yourself. Player structure, site changes and public access can still prevent a particular download.

## Language and source limits

The app interface is English and Arabic. French, German and Spanish website guides explain those existing controls; they do not add application interface languages. Choosing a region does not change the app's capabilities or bypass a site's restrictions.

A higher audio bitrate, WAV or FLAC output cannot restore details absent from the source. Automatic may be the only honest option for unknown audio properties. Private, sign-in-only and DRM-protected media are unsupported. Only save media you have permission to download.
